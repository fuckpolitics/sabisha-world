# Сабиша · личная вселенная

Статический русский Y2K/webpunk-сайт: HTML, CSS, JavaScript. Опубликован на https://fuckpolitics.github.io/sabisha-world/.
Вход только по коду **2610**. Аккаунты и почта не нужны.

## Хранение

Один общий мир хранится в Supabase через RPC с проверкой кода на сервере. В клиенте только публичный publishable key. Закрытые таблицы недоступны напрямую. Код 2610 известен из исходников: любой знающий код получает доступ ко всему миру.
Изменения автоматически сохраняются в localStorage и отправляются в облако. Без сети очередь остаётся на устройстве. После подключения синхронизация повторяется. На другом устройстве тот же код загружает облачную копию. Если два устройства изменяли записи одновременно, настройки позволяют сохранить местный JSON и выбрать версию.
Хранятся последние 30 облачных версий; доступны восстановление и JSON-экспорт. Это не обещание вечного хранения: удаление локальных данных до отправки или недоступность сервиса могут помешать восстановлению.

Сохраняются записи, черновики форм, рисунок, друзья и анкеты, задачи, квесты, мечты, настроение, капсула, созвездие, прогресс пазла и лабиринта. Анкета друга открывается по отдельной ссылке, не раскрывая записи; ответы появляются автоматически.

## Разработка

Запуск: python3 -m http.server 4173 --directory docs
Проверка: node --check docs/app.js && node --check docs/cloud.js
GitHub Pages: main, /docs. Зависимость Supabase JS 2.118.0 закреплена в docs/vendor.
SQL-изменения: schema.sql, private-functions.sql, затем single-world.sql; первые две схемы — прежняя модель, текущая использует private.single_*.
Счётчик использует предположительное время 04:50 Москвы (UTC+4 в 2012), точное время в интерфейсе не показывается.
