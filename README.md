# Сабиша · личная вселенная

Подарок к четырнадцатилетию. Полностью статический сайт на русском в стиле Y2K/webpunk: HTML, CSS и JavaScript, без сборки, сервера, API-ключей и базы данных.

## Запуск

Откройте `docs/index.html` в браузере или выполните:

```sh
python3 -m http.server 4173 --directory docs
```

Перейдите на http://localhost:4173. Код входа: **2610**.

## Разделы

Рабочий стол со счётчиком жизни, настроение дня, друзья с рейтингом и сортировкой, список врагов, календарь и задачи, рисовалка с PNG-экспортом, мастерская Minecraft-квестов, дневник, мечты, мини-пазл, Патрик и Андрей, персональные поздравления, капсула времени, таймер фокуса, ночное оформление и резервные копии JSON.

**Специальный подарок** намеренно заблокирован. Он не открывается по дате или коду: заменить функцию `gift()` в `docs/app.js`, когда подарок будет придуман.

## Данные и время

- Записи сохраняются в `localStorage` под ключом `sabisha-world-v1` на конкретном устройстве и в конкретном браузере. Между устройствами можно переносить JSON-копию через настройки.
- Никакие записи дневника, друзей или задачи не отправляются в GitHub.
- Вход с кодом и блокировка капсулы — только элементы интерфейса, не криптографическая защита. Код виден в исходниках.
- Дата рождения: 26.10.2012, 04:50, Москва. Тогда Москва была **UTC+4**, поэтому начало счётчика — `2012-10-26T04:50:00+04:00`.
- Календарная дата для настроения, капсулы и дня рождения определяется по `Europe/Moscow`.
- Шрифты загружаются из Google Fonts; при отсутствии сети используются системные замены. Всё остальное работает локально.

## GitHub Pages

В Settings → Pages выбрать Deploy from a branch → main → `/docs`. Файл `.nojekyll` отключает ненужную обработку Jekyll. Публикация из приватного репозитория зависит от тарифа GitHub.
